imageseven

A system for consistent pages and tools.

Taken from imageseven.com.au. Use it to build marketing sites, landing pages, and applications that share one type scale, one spacing scale, and one component set. Editorial pages use the brand scale. Product UI uses the interface scale. Dark mode is part of the system. Commerce patterns are not.
